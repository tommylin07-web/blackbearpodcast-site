关于节目

为什么叫
黑熊电台？

黑熊是一种独居、有主见、不合群的动物。 它不需要任何人的认可，只是按照自己的节奏，在山林间来去。 这档节目想做的，就是这样一个麦克风—— 不追流量，不蹭热点，只说真正想说的话。

每期节目我们会聊厦门这座城市、聊生活方式、自然、旅行和创作， 有时候有嘉宾，有时候就一个人坐在麦克风前。 双周更新，时长约40分钟到2小时不等。

如果你也习惯一个人在通勤路上、跑步时、 或者深夜失眠时听点什么——欢迎来这里坐坐。

PodClip Matrix

把一期长播客自动切成竖屏短视频，一键分发到小红书 / 视频号 / 抖音 / YouTube。这就是黑熊电台每天自动发片背后的真实生产管线——现已 MIT 开源。

  • 🎬 整期 → 切片：词级字幕 + 封面卡 + 片尾品牌卡，Remotion 渲染竖屏短视频
  • 🚀 多平台分发：一条命令发小红书 / 视频号 / 抖音，YouTube 走官方 API
  • 🖥️ 本地控制台：转写 / 渲染 / 逐平台发布 / 看状态，全在浏览器点，不碰命令行
  • ⏰ 每日全自动：定时渲染新片 + 挑没发过的 + 发布，登录过期推微信提醒
